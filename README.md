# Bug Journal

Create a developer-focused web application called Bug Diary that helps software developers save, organize, and search their debugging experiences so they never have to solve the same issue twice. The app should allow users to create bug entries with fields such as bug title, description of the issue, error message/logs, technology or framework involved (Java, React, Docker, PostgreSQL, etc.), root cause, solution/fix applied, debugging steps followed, code snippets, tags, difficulty level, and date resolved. The application should have a clean developer-friendly UI with a dashboard displaying saved bugs as cards, search functionality, filtering by technology/tags/difficulty, and the ability to edit, delete, and favorite important fixes. Include a dark developer theme with a terminal/code-inspired design, syntax highlighting for code snippets, and a simple statistics section showing bugs fixed, frequently used technologies, and debugging trends. The goal is to create a personal knowledge base where developers can quickly document, revisit, and learn from their past debugging experiences.
